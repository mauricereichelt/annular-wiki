# Plots

**Annular** ist der Name des *Universums*, nicht einer einzelnen Geschichte. In diesem Ordner liegen die einzelnen Geschichten - unabhängig voneinander erzählbar, verankert in derselben Welt.

## Trennlinie

| Ebene | Wo | Inhalt |
|---|---|---|
| **Universum** | Wurzel des Wikis | [Menschen](../Menschen/README.md), [Orte](../Orte/README.md), [Kulturen](../Kulturen/), [Technik](../Technik/README.md), [Welt](../Welt/README.md) - gilt für alle Geschichten |
| **Plot** | `Plots/<Plot>/` | Kapitelstruktur, Zeitleiste, Szenen - gilt nur für diese eine Geschichte |

Figuren und Orte liegen **oben**, auch wenn sie derzeit nur in einer Geschichte vorkommen. Erst wenn eine zweite Geschichte sie nicht braucht, lohnt eine feinere Trennung.

**Ordnernamen sind dauerhaft generisch** - `Plot-1`, `Plot-2`, … - und tragen **nie** den Werktitel. Der Titel steht ausschließlich in der `README.md` des jeweiligen Plots und in [SUMMARY.md](../SUMMARY.md). So bleibt ein Titelwechsel eine Änderung an zwei Stellen statt an hundert Links.

Figuren und Orte liegen **oben** im Universum, nicht im Plot-Ordner - auch dann, wenn sie nur in einer Geschichte vorkommen.

## Feste Regel: das Geheimnis der Erbauer

**Wer die Portalringe erbaut hat, wird niemals aufgelöst - in keiner Geschichte.**

Künftige Plots erzählen ausschließlich von **Nutzern** der Ringe, nie von ihren Erfindern. Auch eine Hochkultur, die die Ringe im Alltag beherrscht, weiß nicht, woher sie stammen. Das schützt den Motor von Plot 1: [Girlin](../Menschen/Nordvolk/Girlin.md) und [Bellbrim](../Menschen/Andere/Bellbrim.md) stochern im Dunkeln, und keine spätere Geschichte darf diese Dunkelheit rückwirkend ausleuchten.
