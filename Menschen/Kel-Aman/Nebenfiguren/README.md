# Nebenfiguren - Kel Aman

Jede Figur bekommt eine **eigene Datei** nach dem [Charakter-Template](../../Charakter-Template.md); wird sie wichtiger, genügt das **Verschieben** eine Ebene höher.

- [Ishmalen](Ishmalen.md) - Häuptling des Clans, Onkel von Sekkan
- [Gulan](Gulan.md) - Vater von Ishmalen und Tanast, früherer Häuptling, tot
- [Sekkan](Sekkan.md) - Neffe des Häuptlings, Ehemann [Girlins](../../Nordvolk/Girlin.md), zusammen ab Jahr +3
- [Tamant](Tamant.md) - Tochter von Girlin und Sekkan, geboren Jahr +4
- [Tanast](Tanast.md) - Sekkans Mutter, Ishmalens Schwester
- [Ikkedas](Ikkedas.md) - Sekkans Vater
- [Aferdassen](Aferdassen.md) - Ikkedas' Vater, tot
- [Abarkan](Abarkan.md) - Ältester aus Ishmalens Rat
- [Nabaon](Nabaon.md) - Abarkans Vater, tot
- [Tawan](Tawan.md) - Azzims Vater, lebt, nur Autorenebene
